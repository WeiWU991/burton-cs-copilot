# ANON RODAN 头盔

- **产品类型**: 滑雪头盔

## 技术特征

### 外壳结构
- **IN-MOLD外壳结构**: 外壳与EPS材料一体成型，分散稀释外力，轻质强韧

### 缓冲系统
- **EPS缓冲层**: 高密度防撞击材料，吸收碰撞能量，轻质透气，在遇到外力冲击时可以起到较好的缓冲效果

### 通风系统
- **自然通风系统**: 从前部吸入新鲜空气并从后部排出湿气，排湿透气，保持干爽

### 调节系统
- **360° BOA调节系统**: 在头盔的后侧通过旋钮调节头盔大小，单手或佩戴手套均可轻松操作，头围可调节，贴合度UP

### 其他特性
- **FIDLOCK磁力吸附按扣**: 单手操作，便捷安全
- **抓绒内衬和耳套**: 舒适保暖
- **音频设备适配**: 兼容音频设备，可安装耳机

## 清洗保养

### 清洗
- 使用少量不含柔顺剂的洗衣液，在40°C左右的温水中清洗，并冲洗两次
- 降低洗衣机转速以减少褶皱
- 不要使用洗衣粉或任何含有衣物柔顺剂、衣物护理液、去污剂或漂白水成分的产品

### 干洗
- 请遵循服装制造商的建议

### 熨烫
- 如果无法使用烘干机，请使用非蒸汽的低温熨斗，在服装上放置一块布后再熨烫，可活化表面的防泼水效果

### 干衣
- 通风晾干或使用中温、低转速的烘干机
- 如果是防泼水面料，烘干后请再多烘20分钟来活化表面的防泼水效果

### 防泼水剂
- 请遵循服装制造商的建议

### 不可漂白
