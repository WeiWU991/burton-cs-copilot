# BURTON SCRIBE Re:Flex 女士固定器

## 产品信息
- **产品ID**: 105521
- **产品名称**: SCRIBE Re:Flex 女士固定器
- **产品类型**: 单板滑雪固定器 (Snowboard Bindings)
- **安装系统**: Re:Flex
- **软硬度**: 中等偏软（新手友好）

## 产品特点

SCRIBE将响应和缓震巧妙的融合，无论滑行风格如何，都能保持柔软、灵活和灵敏，处于力量和灵敏之间的平衡点，让您一整天的滑行乐趣十足。

### 技术特征

1. **Reactstrap大绑带**
   - 3D立体弯曲设计
   - 牢固贴合脚踝
   - 舒适贴合，防止重心前倾时雪鞋脱落
   - 反应灵敏，自由施展动作不拘束

2. **Supergrip Capstrap小绑带**
   - 舒适包裹脚趾，抓地力强
   - 舒适包裹不勒脚
   - 同时防止重心后倾时滑雪鞋脱落

3. **Re:Flex安装系统**
   - 采用LIVING-HINGE安装盘，能够更轻更好地释放雪板弹性
   - 底盘进行了缓震设计
   - 适配各种主流单板
   - 轻盈缓震

4. **DialFLAD**
   - 通过DialFLAD旋转调节按钮
   - 快速调整背板旋转和前倾角度

## 固定器软硬对比

### 软固定器
- 给予滑手更多的自由度和动作的施展度，容错率高
- 让喜欢Freestyle的滑手能更自然地做动作
- 对于新手很友好

### 硬固定器
- 雪板操控更精准，反馈更直接
- 雪鞋、固定器与雪板之间的能量传导更灵敏

## 安装系统说明

### Re:Flex系统
- 相较于普通传统圆盘固定器，Re:Flex固定器采用了Living-Hinge安装盘
- 更轻也更好地释放雪板弹性
- 底盘进行了缓震设计
- 提供适配于主流单板的安装系统

### EST系统
- EST固定器脚下没有金属螺丝，提供了更好地板底感知
- 同时更易调整到合适的站姿角度
- EST固定器与BURTON CHANNEL滑轨系统适配
- 给你合二为一的完整体验
- 充分释放雪板弹性的同时，提供更好地板底感知
