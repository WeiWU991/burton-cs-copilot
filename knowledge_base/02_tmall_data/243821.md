# 产品信息

## 1. 产品特征与专业技术
*   **Youth Imprint热定型内靴:** 保暖透气，舒适贴合。内靴配置鞋带，方便将内靴系紧，增加包裹感。
*   **BOA系带系统:** 松紧自由调节，紧密包裹不压迫。通过旋钮控制整个鞋带，牢牢锁紧脚部的同时舒适自如。
*   **DYNOLITE外底:** 轻盈、舒适、缓震。提升板感和足部支撑，可承受反复冲击。
*   **TOTAL COMFORT结构:** 提供开箱即用的畅快感受。整体的舒适结构，消除鞋与脚部的磨合期，开箱即可使用，畅享滑雪乐趣。
*   **儿童特有技术“保暖&可生长空间”:**
    *   青少年及儿童雪鞋没有内靴，都会配备3M新雪丽保暖科技。
    *   小朋友的脚普遍会长的很快，BURTON在儿童雪鞋中设计了可生长空间技术。
    *   当小朋友觉得雪鞋小了的时候可将雪鞋内部的鞋垫走一层，可立刻让雪鞋增大尺码，不再需要每个雪季都买一双新的雪鞋。
*   **内胆设计Boot Liners:**
    *   **Imprint:** 不同等级的Imprint内靴采用不同的技术，包含热定型科技和脚踝固定科技。Imprint 1、2、3的内靴价格不同，意味着雪鞋的支撑等性能指标的不同。可以根据您自身滑行的需要，选择合适的内靴类型。
    *   **Life:** Life内靴采用轻质材料，提高功能性的同时不失舒适的穿戴感。通过增加鞋舌的硬度增加灵敏度和耐久性，提供额外脚跟部位固定，加强了内胆内侧和横向支撑度，同时不影响脚趾到脚跟的纵向弯曲灵活性。
    *   **Life+:** 在Life的基础上，升级了鞋垫，且增加了DRYRIDE恒温材料，进一步增加保暖性。
*   **热定型Heat Molding:**
    *   所有雪鞋内靴都会渐渐贴合你的脚型；
    *   滑行过程中脚产生的热量也能起到热定型的作用；
    *   在滑雪前在室内穿着新雪鞋行走一段时间可使雪鞋更贴合脚型；
    *   LIFE与LIFE+的内胆所需热定型时间更短，从第一天穿着就会比其他内胆舒适。
*   **优化女性特有“TRUE FIT”科技:**
    *   TRUEFIT专为女性设计，根据女性腿部结构，适当降低了鞋帮，在靴口增加弹性三角片以更适合女性腿部特征，有利于更好地感知和操控雪板。
    *   雪鞋前端增添了空间，雪鞋更保暖更舒服。
    *   女款特有的后跟设计让雪鞋更贴合。
    *   内胆后端更矮。
    *   调整了小腿处的周长。

**雪鞋尺码挑选建议:**
1.  根据日常穿着鞋码选择即可。
2.  系紧鞋带站起来，感受脚趾位置。
3.  屈膝模仿单板站姿，脚趾应刚好贴近鞋头内壁。
4.  雪鞋使用几次后，会随脚型释放部分空间。
5.  如果太顶或者太松，即为尺码不合适。
*在正常站立情况下，雪鞋感受比较紧是正常的，相对紧致的包裹性是为了提供更高的安全性能。*

**如何找到合适尺码的鞋子?**
1.  系紧鞋带并站起来。四处走走，跳跃，模仿单板站姿。
2.  感受脚趾的位置。屈膝单板站姿的时候，脚趾应当刚好贴近鞋头内壁，不顶脚也不太远。
3.  雪鞋使用几次后，它会随脚形释放部分空间。
4.  如果太顶或者太松，便不是合适的尺码。
*   **合适:** 站立姿势时，拇指紧贴鞋头内壁；前刃姿势时，脚趾与鞋头内壁略紧贴但不接触。
*   **偏大:** 站立和前刃姿势时，脚趾均未接触鞋头内壁。
*   **偏小:** 站立姿势时，脚趾已感到挤压和不适。
