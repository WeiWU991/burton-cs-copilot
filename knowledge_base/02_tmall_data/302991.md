## 1. 产品特征与专业技术
*   **Step On® 系统:**
    *   **为什么选择Step On?:** 新手友好，快速穿脱。
    *   **穿脱指南:** 没有绑带一样安全 / 穿脱只需几秒 / 不用摘手套 解放双手。
    *   **出发准备:** 清除鞋底和固定器上的雪、冰或沙砾，确保将裤脚塞入到雪鞋的裤口夹中不遮挡鞋跟卡扣。系紧带系，准备就绪。
    *   **一踩即上:** 脚跟对准固定器背板，向下踩，直到听到“咔哒”两声，表示鞋跟已锁定。身体稍向前压，用小腿、左右轻轻晃动，听到再有“咔哒”两声，确认前挂钩也已卡好。
    *   **一提即下:** 拉下释放拉杆 → 松开 → 提脚跟 → 重心前移 → 扭脚脱出，完成！
    *   **适配说明:** STEP ON的固定器与雪鞋仅互相适配，不与其他固定器或雪鞋适配。

*   **3大新升级:**
    *   **脚感升级:** 相比常规款，这款滑雪鞋在外靴小腿收口处以及脚踝四周采用了柔韧材料，提升横向柔韧度，让你在滑行过程中脚部更舒适。
    *   **内衬锁边升级:** 在滑雪鞋与固定器小绑带接触摩擦部位，升级了锁边设计，以增加缓冲，提升舒适感。
    *   **裤腿夹升级:** 可以轻松收纳裤腿，减轻固定器给脚踝带来的束缚感。

*   **上下双区BOA®适配系统:** 上下单独调节，提升贴合感。双旋钮可调节不同部位松紧，牢牢锁紧脚部的同时舒适自如。

*   **Imprint3 热定型内靴:** 保持温暖干爽，支撑足弓。热循环科技，可持续锁住鞋内热量，加速吸湿排汗，保持温暖干爽。两侧加强了对足弓的支撑，让脚部更稳定。

*   **Vibram®外底:** 轻便耐磨，抓地力强。使用立体齿纹防滑爪，加大防滑面积，提升脚感与舒适性。

*   **TOTAL COMFORT结构:** 提供开箱即用的畅快感受，现在出发。整体的舒适结构，消除鞋与脚部的磨合期，开箱即可使用，畅享滑雪乐趣。

*   **热循环系统:** DRYRIDE热循环系统，有效排湿，保持干燥，采用3MThinsulate保暖材料，鞋底“睡袋”科技，反射脚部产生的热辐射。持久保持干爽舒适！

*   **ReBounce:** BURTON研发的雪鞋缓震科技，采用PU发泡材料，让你的脚更贴近缓震层。

*   **女士专用雪鞋: True Fit:** True Fit专为女性设计，根据女性腿部结构，适当降低了鞋帮，在靴口增加弹性三角片以更适合女性腿部特征，有利于更好地感知和操控雪板。这项研究项目涉及1,500小时的拟合测试，200多个用于雪地测试的原型。

*   **热定型内靴Heat Molding:**
    *   所有雪鞋内靴都会渐渐贴合你的脚型；
    *   滑行过程中脚产生的热量也能起到热定型的作用；
    *   在滑雪前在室内穿着新雪鞋行走一段时间可使雪鞋更贴合脚型；
    *   LIFE与LIFE+的内胆所需热定型时间更短，从第一天穿着就会比其他内胆舒适。

## 2. 尺码详细信息
### **如何找到合适尺码的鞋子?**
1.  系紧鞋带并站起来。四处走走，跳跃，模仿单板站姿。
2.  感受脚趾的位置。屈膝单板站姿的时候，脚趾应当刚好贴近鞋头内壁，不顶脚也不太远。
3.  雪鞋使用几次后，它会随脚形释放部分空间。
4.  如果太顶或者太松，便不是合适的尺码。
*   站立姿势时，拇指紧贴鞋头内壁；前刃姿势时，脚趾与鞋头内壁略紧贴但不接触。
