# 清洗保养

您可以在产品内侧找到清洁保养的标签，请遵循上面的说明进行清洁保养。
GORE-TEX产品不仅持久耐用，有规律的清洁保养能保持产品出色的功能，并延长使用寿命。

* **[图标：水洗盆] 清洗**
  * 洗衣机中倒入少量不含柔顺剂的洗衣液，在40℃左右的温水中清洗，并冲洗两次；
  * 降低洗衣机转速以减少褶皱；
  * 不要使用洗衣粉或任何含有衣物柔顺剂、衣物护理液、去污剂或漂白水成分的产品

* **[图标：熨斗] 熨烫**
  * 如果无法使用烘干机，请使用非蒸气的低温熨斗，在服装上放置一块布后再熨烫，可活化表面的防泼水效果

* **[图标：带有圆圈的正方形] 干衣**
  * 通风晾干或使用中温、低转速的烘干机
  * 如果是防泼水面料，烘干后再多烘20分钟来活化表面的防泼水效果

* **[图标：带有P字的圆圈] 干洗**
  * 请遵循服装制造商的建议

* **[图标：打着伞的雨滴] 防泼水剂**
  * 请遵循服装制造商的建议

* **[图标：打叉的三角形] 不可漂白**
