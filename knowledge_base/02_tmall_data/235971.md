## 1. 产品特征与专业技术
*   **Step On® 穿脱步骤:**
    *   **踏上步骤: 脚跟→脚趾**
        1.  脚后跟顺着脚跟接合夹处踏入
        2.  向前倾斜，踩入前侧左右脚趾处
        3.  听到轻微咔嗒声后，左右轻微晃动一下，确认都固定住了
    *   **踏出步骤: 拉杆→释放**
        1.  拉动固定器后跟的杠杆
        2.  扭动你的脚即可踏出

*   **Imprint™ 3 热定型内靴:** 保持温暖干爽，支撑足弓。采用热循环科技，可持续锁住鞋内热量，加速吸湿排汗，保持温暖干爽。两侧加强了对足弓的支撑，让脚部更稳定。

*   **BOA® 系带&绑带系统:** 控制顶部旋钮将雪鞋系紧，可通过调整下方BOA绑带带来额外的包裹性。BOA系带系统是依靠旋钮来控制整个鞋带，以新英格兰线材代替传统的鞋带，非常轻盈耐久。
    *   便捷的旋钮控制
    *   不会打结，易于更换

*   **TOTAL COMFORT 技术:** 整体的舒适结构，提供开箱即用的畅快感受，现在出发。消除鞋与脚部的磨合期，开箱即可使用，畅享滑雪乐趣。

*   **VIBRAM® 外底:** 轻便耐磨，抓地力强。使用立体齿纹防滑爪，加大防滑面积，提升脚感与舒适性。

*   **热定型内靴 (Heat Molding):**
    *   所有雪靴内靴都会渐渐贴合你的脚型；
    *   滑行过程中脚产生的热量也能起到热定型的作用；
    *   在滑雪前在室内穿着新雪靴行走一段时间可使雪靴更贴合脚型；
    *   LIFE与LIFE+的内胆所需热定型时间更短，从第一天穿着就会比其他内胆舒适。

*   **女士专用雪靴 (True Fit):** TRUE FIT专为女性设计，根据女性腿部结构，适当降低了鞋帮，在靴口增加弹性三角片以更适合女性腿部特征，有利于更好地感知和操控雪板。雪靴前端增添了空间，雪靴更保暖更舒服。女款特有的后跟设计让雪靴更贴合。内胆后端更矮。调整了小腿处的周长。该项研究项目涉及1,500小时的拟合测试，200多个用于雪地测试的原型。

*   **热循环系统:** DRYRIDE热循环系统，有效排湿，保持干掉，采用3M Thinsulate™保暖材料，鞋底“睡袋”科技，反射脚部产生的热辐射。持久保持干爽舒适！

*   **ReBounce 缓震科技:** BURTON研发的雪靴缓震科技，采用PU发泡材料，让你的脚更贴近缓震层。

*   **内胆设计 (Boot Liners) 通用技术说明:**
    *   **Imprint:** 不同等级的Imprint内靴采用不同的技术，包含热定型科技和脚踝固定科技。Imprint 1、2、3的内靴价格不同，意味着雪靴的支撑等性能指标的不同。可以根据您自身滑行的需要，选择合适的内靴类型。
    *   **Life:** Life内靴采用轻质材料，提高功能性的同时不失舒适的穿戴感。通过增加鞋舌的硬度增加灵敏度和耐久性，提供额外脚跟的位固定，加强了内胆内侧和横向支撑度，同时不影响脚趾到脚踝的纵向弯曲灵活性。
    *   **Life+:** 在Life的基础上，升级了鞋垫，且增加了DRYRIDE恒温材料，进一步增加保暖性。

## 2. 尺码详细信息
**雪鞋尺码挑选建议:**
1.  根据日常穿着鞋码选择即可
2.  系紧鞋带站起来，感受脚趾位置
3.  屈膝模仿单板站姿，脚趾应刚好贴近鞋头内壁
4.  雪靴使用几次后，会随脚型释放部分空间
5.  如果太顶或者太松，即为尺码不合适

**如何找到合适尺码的鞋子?**
1.  系紧鞋带并站起来。四处走走，跳跃，模仿单板站姿。
2.  感受脚趾的位置。屈膝单板站姿的时候，脚趾应当刚好贴近鞋头内壁，不顶脚也不太远。
3.  雪靴使用几次后，它会随脚形释放部分空间。
4.  如果太顶或者太松，便不是合适的尺码。

*站立姿势时，拇指紧贴鞋头内壁；前刃姿势时，脚趾与鞋头内壁略紧贴但不接触。*

## 3. 清洗维护保养
*   **清洗:**
    *   洗衣机中倒入少量不含柔顺剂的洗衣液，在40°C左右的温水中清洗，并冲洗两次；
    *   降低洗衣机转速以减少褶皱；
    *   不要使用洗衣粉或任何含有衣物柔顺剂、衣物护理液、去污剂或漂白水成分的产品。
*   **熨烫:**
    *   如果无法使用烘干机，请使用非蒸汽的低温熨斗，在服装上放置一块布后再熨烫，可活化表面的防泼水效果。
*   **干衣:**
    *   通风晾干或使用中温、低转速的烘干机。
    *   如果是防泼水面料，烘干后再请多烘20分钟来活化表面的防泼水效果。
*   **干洗:**
    *   请遵循服装制造商的建议。
*   **防泼水剂:**
    *   请遵循服装制造商的建议。
*   **不可漂白**
