## 1. 产品特征与专业技术
*   **PERCEIVE 镜片:** 高清注塑感知镜片，过滤多余光线并增强明暗对比，优化滑手对雪况的清晰观察。
*   **MAGNA-TECH® 磁吸科技:** 先进的磁吸换片科技，轻松契合，单手快速更换镜片，应对环境挑战，带来流畅体验，锁定到位安全牢固。
*   **MFI® 磁吸面罩:** 快速连接面罩雪镜，锁温透气，轻盈贴合，有效抵御风雪和紫外线。
*   **大尺寸双密度全框:** 软硬兼合，轻质耐久。
*   **柱面镜片:** 柱面外观，演绎绊风格。
*   **MILE 25 限量版纪念图案:** 将品牌标识元素以网格化形式重构，呈现具有纪念意义的视觉细节。
*   **亚洲版型:** 加厚鼻梁处海绵衬垫，舒适贴合，适配亚洲脸型。
*   **防滑硅胶雪镜带:** 自由调节，牢固定位。
*   **快速磁吸换片:** 单手换片，快速切换不同场景。

### 场景选择与镜片色调 (VLT)
VLT：即镜片透光率，百分比越小，透过镜片进到眼睛的光线越少。光线充足时，VLT范围控制在5-20%，深色镜片将会阻挡更多光线；能见度低时，VLT范围控制在60-90%，浅色镜片将会促进光线进入。

| SUNNY RED | S3 14% VLT | 阳光明媚 |
| SUNNY BRONZE | S3 17% VLT | 阳光明媚 |
| VARIABLE BLUE | S2 21% VLT | 晴天与多云 |
| VARIABLE GREEN | S2 22% VLT | 晴天与多云 |
