## 1. 产品特征信息 (基本信息 & 核心技术)

### 基本信息
* 青少年专用镜框设计
* **LOW BRIDGE FIT (亚洲低鼻梁设计):** 根据亚洲人面部结构调整鼻梁处泡沫高度，双层面部海绵，增加贴合度。
* **镜片设计:** 柱面注塑镜片，减轻了周边视野失真的影响。
* **MFI技术:** 一体化磁吸面罩。
* **绑带设计:** 防滑硅胶绑带，可戴于眼镜外 (OTG光学眼镜兼容)。
* **透气系统:** 全尺寸透气轨道，增加空气流通，排湿透气。
* **其他相关性能:** 高清视界 (HD)、UV防护 (紫外线防护)、防眩光、防冲击力、头盔适用。
* **额外附赠 (套装礼赠):** 雪镜袋、MFI面罩、供替换的副镜片 (部分款式)、镜片收纳盒、微纤维护目镜袋 (*因生产批次不同，礼赠可能略有不同，请以收到实物为准*)。

### 核心技术支持
* **MFI®磁罩技术:** 快速将面罩无缝连接到护目镜上，保护脸部不受寒风雨雪及紫外线的干扰，配合通风，防止起雾，视野更清晰。锁温透气，轻盈贴合。
* **PERCEIVE:** 高清注塑感知镜片。过滤多余光线并增强明暗对比，优化滑手对雪况的清晰观察。
* **MAGNA-TECH®:** 先进的磁吸换片科技。轻松契合，单手快速更换镜片，应对环境挑战，带来流畅体验。

## 2. 镜片挑选 (场景选择与镜片色调)

**邂逅不同天气情况，PERCEIVE 以9种不同VLT镜片，轻松应对各种滑行环境。**

> **什么是VLT？** > 即镜片透光率。百分比越小，透过镜片进到眼睛的光线越少。光线充足时，VLT范围控制在5-20%，深色镜片将会阻挡更多光线；能见度低时，VLT范围控制在60-90%，浅色镜片将会促进光线进入。

| 镜片型号 / 颜色 | VLT透光率 | 适用天气场景 |
| :--- | :---: | :--- |
| **SUNNY ONYX S4** | 6% | 阳光明媚 |
| **SUNNY RED S3** | 14% | 阳光明媚 |
| **SUNNY BRONZE S3** | 17% | 阳光明媚 |
| **VARIABLE BLUE S2** | 21% | 晴天与多云 |
| **VARIABLE GREEN S2** | 22% | 晴天与多云 |
| **VARIABLE VIOLET S2**| 34% | 半日照、多云与雪天 |
| **CLOUDY PINK S1** | 53% | 阴天、能见度低的天气、雪天 |
| **CLOUDY BURST S2** | 53% | 阴天、能见度低的天气、雪天 |
| **CLOUDY NIGHT S2** | 72% | 阴天、能见度低的天气、雪天 |

## 5. 清洗保养

您可以在产品内侧找到清洁保养的标签，请遵循上面的说明进行清洁保养。
*(注：GORE-TEX产品不仅持久耐用，有规律的清洁保养能保持产品出色的功能，并延长使用寿命。)*

* **清洗**
  * 洗衣机中倒入少量不含柔顺剂的洗衣液，在40°C左右的温水中清洗，并冲洗两次；
  * 降低洗衣机转速以减少褶皱；
  * 不要使用洗衣粉或任何含有衣物柔顺剂、衣物护理液、去污剂或漂白水成分的产品。
* **干洗**
  * 请遵循服装制造商的建议。
* **防泼水剂**
  * 请遵循服装制造商的建议。
* **熨烫**
  * 如果无法使用烘干机，请使用非蒸汽的低温熨斗，在服装上放置一块布后再熨烫，可活化表面的防泼水效果。
* **干衣**
  * 通风晾干或使用中温、低转速的烘干机；
  * 如果是防泼水面料，烘干后再多烘20分钟来活化表面的防泼水效果。
* **不可漂白**
