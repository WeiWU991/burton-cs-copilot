# 产品信息

**产品名称:** ANON M4 CYLINDRICAL 柱面亚洲版滑雪镜
**核心定位:** 瞬应万变，视野无界。
**产品类型:** 柱面镜片滑雪镜，适配亚洲脸型。

---

## 1. 产品特征与专业技术

### 核心技术支持
* **PERCEIVE 镜片:** 高清注塑感知镜片，通过过滤多余光线并增强明暗对比，优化滑手对雪况的清晰观察。
* **MAGNA-TECH® 磁吸科技:** 先进的磁吸换片科技，轻松契合，支持单手快速更换镜片，应对环境挑战，锁定到位且安全牢固。
* **MFI® 磁吸面罩:** 快速连接面罩与雪镜，锁温透气且轻盈贴合，有效抵御风雪和紫外线。

### 细节展示与相关性能
* **柱面镜片:** 经典柱面外观，演绎复古风格。
* **亚洲版型:** 加厚鼻梁处海绵衬垫，舒适贴合，专门针对亚洲脸型设计。
* **大尺寸双密度全框:** 软硬兼合，轻质耐久。
* **防滑硅胶雪镜带:** 自由调节，确保牢固固定。
* **OTG光学眼镜兼容:** 支持在雪镜内佩戴光学近视眼镜。
* **全方位保护:** 具备紫外线防护、防眩光、防冲击力等性能。

### 视野范围 (M4 柱面镜)
* **水平视野:** 188°
* **垂直视野:** 96°
* **镜框尺寸:** 宽度 184mm / 高度 103mm

## 4. 清洗维护保养

* **清洗:** 使用少量不含柔顺剂的洗衣液，在40°C左右温水中清洗并冲洗两次；降低洗衣机转速；严禁使用洗衣粉、漂白水或含柔顺剂的护理液。
* **熨烫:** 若无烘干机，可用非蒸汽低温熨斗（垫布）熨烫以活化防泼水效果。
* **干衣:** 通风晾干或中温低转速烘干；防泼水面料建议烘干后再多烘20分钟。
* **注意:** 严禁漂白，干洗及防泼水剂请遵循制造商建议。
