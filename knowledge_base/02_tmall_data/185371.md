## 1. 产品特征与科技信息

### 基本信息
* 中性框架设计
* 预弯曲柱面镜片，更加贴合面部形状
* 双层面部海绵，排湿抓绒层更贴合舒适
* 轻质耐久镜框，在寒冷气温下也可保持柔韧
* 内置清晰防雾科技，可增加清晰度和视野
* 全尺寸透气轨道，增加空气流通，排湿透气
* 额外附赠MFI面罩、雪镜袋

### 产品科技细节
* **优质镜片，不止是抗UV:** 专为雪地环境打造的高对比度优质镜片。高清视野，景致还原。
* **强劲防雾科技:** 结合全尺寸与其顶部透气孔形成立体通风换气系统。长效防雾，安全防护。
* **多层面部海绵:** 恰到好处的贴合。
* **防滑硅胶绑带:** 可与头盔贴合，不易滑落。
* **近视眼镜适配 (OTG):** 近视卡槽设计，可卡近视眼镜。

### 核心技术支持
* **PERCEIVE:** 高清注塑感知镜片。过滤多余光线并增强明暗对比，优化滑手对雪况的清晰观察。
* **MAGNA-TECH®:** 先进的磁吸换片科技。轻松契合，单手快速更换镜片，应对环境挑战，带来流畅体验。
* **MFI®:** 快速连接面罩雪镜。锁温透气，轻盈贴合，有效抵御风雪和紫外线。

### 其他相关性能
* OTG光学眼镜兼容、防滑硅胶绑带、紫外线防护、防眩光、防冲击力、亚洲低鼻梁设计。

### 套装礼赠
* MFI磁吸面罩、供替换的副镜片、镜片收纳盒、微纤维护目镜袋。（*注：因生产批次不同，礼赠可能略有不同，请以收到实物为准。*）

## 3. 镜片挑选 (场景选择与镜片色调)

**邂逅不同天气情况，PERCEIVE 以9种不同VLT镜片，轻松应对各种滑行环境。**

> **VLT:** 即镜片透光率，百分比越小，透过镜片进到眼睛的光线越少。光线充足时，VLT范围控制在5-20%，深色镜片将会阻挡更多光线；能见度低时，VLT范围控制在60-90%，浅色镜片将会促进光线进入。

| 镜片型号 / 颜色 | VLT透光率 | 适用天气场景 |
| :--- | :---: | :--- |
| **SUNNY ONYX S4** | 6% | 阳光明媚 |
| **SUNNY RED S3** | 14% | 阳光明媚 |
| **SUNNY BRONZE S3** | 17% | 阳光明媚 |
| **VARIABLE BLUE S2** | 21% | 晴天与多云 |
| **VARIABLE GREEN S2** | 22% | 晴天与多云 |
| **VARIABLE VIOLET S2**| 34% | 半日照、多云与雪天 |

| **CLOUDY BURST S2** | 53% | 阴天、能见度低的天气、雪天 |
| **CLOUDY NIGHT S2** | 72% | 阴天、能见度低的天气、雪天 |
