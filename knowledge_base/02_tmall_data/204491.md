# 产品信息

## 1. 产品特征与专业技术

* **复曲面镜片 (Toric Lens):** 结合了各种镜片的设计特点，改善了清晰度和周边视野，提高了通风孔体积。
* **核心技术支持:**
    * **PERCEIVE:** 高清注塑感知镜片，过滤多余光线并增强明暗对比，优化滑手对雪况的清晰观察。
    * **MAGNA-TECH®:** 先进的磁吸换片科技，轻松契合，支持单手快速更换镜片。
    * **MFI®:** 快速连接面罩雪镜，锁温透气，轻盈贴合，有效抵御风雪和紫外线。
* **其他相关性能:**
    * 内置清晰防雾科技。
    * OTG 光学眼镜兼容。
    * 防滑硅胶绑带、紫外线防护、防眩光、防冲击力。
    * 亚洲低鼻梁设计。
* **包含配件:** 含镜片收纳盒。

## 4. 清洗维护保养指南

* **清洗:**
    * 洗衣机中倒入少量不含柔顺剂的洗衣液，在40°C左右温水中清洗并冲洗两次。
    * 降低洗衣机转速以减少褶皱。
    * **禁止使用**洗衣粉、衣物柔顺剂、护理液、去污剂或漂白水。
* **熨烫:** 若无法使用烘干机，请使用非蒸汽低温熨斗，在服装上放置垫布后熨烫，可活化表面防泼水效果。
* **干衣:**
    * 通风晾干或使用中温、低转速烘干机。
    * 防泼水面料烘干后再多烘20分钟以活化防泼水效果。
* **干洗/防泼水剂:** 请遵循服装制造商建议。
* **不可漂白:** 严禁使用漂白成分。
